# 덜내요(가제) 15초 홍보 영상

두 가지 버전의 15초 세로 홍보 영상(1080×1920)과 게시 문구를 모아 둔 폴더예요.

| 버전 | 폴더 | 무드 | 영상 |
|---|---|---|---|
| 기본 | [`basic/`](basic/) | 토스 블루, 앱 화면 줌인 | `promo_15s.mp4` |
| 시크 | [`chic/`](chic/) | 블랙 + 본화이트 + 애시드 라임, 큰 타이포 | `promo_chic_15s.mp4` |

시크 버전은 `chic/` 안에 영상 소스가 함께 있어요: `index.html`(장면), `assets/`(앱 캡처), `audio.py`(나레이션·BGM 생성), `audio/`, `render.py`(프레임 렌더).
