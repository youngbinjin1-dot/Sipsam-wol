# Spec.md — 무엇을 만드는가

산출물 2개: **① 페이크 도어 랜딩 `index.html`** (수요 검증) / **② 앱 모의실행 `app.html`** (흐름·이해도 검증).
토스 인앱 서비스를 가정하므로 **회원가입·로그인 화면은 없다.** 첫 진입 때 동의 화면만 거친다.

## ① 페이크 도어 `index.html`
| 영역 | 내용 |
|---|---|
| 히어로 | 메인 카피(A/B/C는 `?v=a|b|c`) + 서브 "카드·월급·월세는 토스가 이미 알고 있어요. 남은 두 달, 어디로 결제할지만 정하세요." |
| 오퍼·신뢰 | "한 달 무료 체험, 끝나고 정하세요." / "환급금에서 한 푼도 떼지 않아요." |
| 슬라이더 미리보기 | 조작 가능한 간단한 슬라이더(신용/체크 비율 → 예시 세금 변화). 예시 숫자임을 표시 |
| 1번 문 | CTA "내 연말정산 바로 보기" → 즉시 "아직 준비 중이에요" 시트 |
| 2번 문 | 시트 안 "1월 연말정산 도우미 + 구독 특별가 알림" 버튼(가격대 표시) |
| 설문 | ① 미리보기 해봤나요 ② 결과 ③ 지금 주로 쓰는 결제 수단 ④ 신용/체크 언제 바꿀지 몰랐나요 |
| 규칙 | 결제·카드 정보·연락처를 받지 않음. 이벤트는 브라우저 localStorage에만 기록 |
| 이벤트 | `view`, `cta1`, `cta2`(가격 버튼), `survey`, `slider_touch` |

## ② 앱 모의실행 `app.html` (PRD 11월 S00~S13)
| 단계 | 화면 | 핵심 |
|---|---|---|
| 시작 | S00 시작 → S01 이용 동의 → 토스 연동 → S02 자동으로 찾은 정보 → S03 질문 카드 | 동의는 맨 앞 한 번. 연동 거부 시 3가지만 직접 입력 |
| 작동 | S04 올해 예상 결과 + **지금 바꿀 수 있는 방법** → S05 카드 사용 슬라이더(신용·체크 따로 비교 표, 큰 지출 여러 건 직접 입력) → S06 저장·알림 → 홈 | 결과보다 방법 제시가 중심 |
| 작동 | 줄이는 법 탭 | 세 묶음: ⏰ 12/31 전에 할 일(결제 수단·월세 12월분·현금영수증·전통시장/대중교통) / ✅ 이미 한 것 확인(병원비·안경·기부 영수증·연금저축·보험료·교육비·청약저축) / 📌 알아두기(기부 제도 안내(권유 아님)·맞벌이·이직·중소기업 청년). 효과 큰 순, 내 플랜에 담기 |
| 작동 | S07 전환 알림 바텀시트 → S08 12월 마무리 리포트 | 문턱 도달 시 한 번만 |
| 마무리 | S09 구독 안내 → S10 구독 동의(시연) → S11 도우미 홈 → S12 자료 비교 → S13 제출 가이드 → 마무리 | 유료 결제 별도 동의, 실제 결제 없음 |

### 줄이는 방법 계산 (예시 모델, 근사)
- 카드 공제: 총급여 25% 초과분부터, 문턱은 신용카드부터 채움, 신용 15%·체크/현금영수증 30%, 한도 300만 원. 소득공제라 한계세율 15% 적용.
- 월세 세액공제: 연 1,000만 원 한도, 총급여 5,500만 이하 17%. 부양가족: 1인 150만 원 소득공제. 병원비: 총급여 3% 초과분 15% 세액공제(대략 구간 입력).
- "모르겠어요"는 계산에서 빼고 "확인 필요"로 표시. 연금저축·IRP는 금액 계산 없이 안내만.
- 카드 포인트·할인 같은 혜택은 계산에 넣지 않음을 슬라이더 화면에 표시.

### 입력 보강
- 월세: 월세 금액 + **올해 낸 개월 수**(기본 11, 1~12) + "12월분도 낼 예정" 토글. 공제 = 월세 × 개월(연 1,000만 원 한도) × 공제율. 직접 입력 화면에도 개월 수 입력칸.
- 큰 지출: 칩(노트북·가전·50만 원) + 항목 이름·금액 직접 입력, 여러 건 추가·삭제, 합계 표시.
- 질문 카드: 월세(+집·전입신고) → 부양가족 → 병원비 → **보험료 → 연금저축·IRP**. 보험료·연금저축은 "네"면 구간 칩이나 직접 입력(만원)으로 금액을 받아 첫 결과에 바로 반영한다. 결혼·출산 질문은 효과가 없어 알아두기 카드로 옮겼다(모두 "아니요"일 때 첫 결과까지 터치 7번).
- 첫 결과 화면 아래에 "다음: 남은 지출, 결제 수단 정하기" 설명 카드와 "카드 결제 수단 정해보기" 버튼을 두고, 해당 화면 제목도 "결제 수단 정하기"로 맞췄다.
- 기부·안경·교육비·청약저축은 줄이는 법 탭에서 입력한다질문에서 이미 답한 병원비·보험료·연금저축은 줄이는 법 탭 맨 위 "앞에서 입력한 것" 카드로 모여 입력칸이 겹치지 않고, 거기서 [수정]할 수 있다("모르겠어요"·민감정보 미동의는 확인 카드가 남고, "아니요"는 숨김). 기부는 새로 쓰는 돈이라 권하지 않고 이미 한 기부 영수증 확인 + 제도 안내 카드만 둔다.

### 줄이는 법 탭의 입력·체크 동작
- **금액 입력 항목**(올해 이미 한 것만): 기부, 안경·렌즈, 보험료, 교육비, 연금저축·IRP, 청약저축(무주택 세대주일 때만 노출). [반영]을 누르면 예상 세금이 바로 바뀌고 홈·결과에 반영된다. 지우기로 되돌릴 수 있다.
  - 추정 계산: 기부 15%, 보험료 한도 100만 원×12%, 교육비 한도 300만 원×15%, 연금저축·IRP 한도 900만 원×15%(총급여 5,500만 이하, 남은 한도 표시), 청약저축 한도 300만 원×40%×한계세율, 안경은 연 50만 원까지 의료비에 합산(총급여 3% 초과분부터 효과).
  - 금액을 넣어도 "1월 간소화 자료로 확정" 안내를 함께 표시한다.
- **월세 12월분**: [12월분 낼게요]를 누르면 공제 개월 수가 늘어 예상에 반영된다.
- **확인했어요 / 해당 없어요**: 눌러도 금액은 바뀌지 않고, 끝낸 항목은 흐리게 아래로 내려가며 홈의 "이번 주 할 일"과 12월 리포트의 "1월에 확인할 것"에서 빠진다. 저장 화면에는 "플랜에 반영한 것"으로 모인다.

### 구독 안내 노출 (체험 중 압박 금지, 자동 전환 없음)
홈 상단 "한 달 무료 체험 중" 카드 / 내 정보 최상단 카드 / 줄이는 법 탭 하단 / 저장 화면 한 줄 / 12월 리포트의 "1월 구독 미리 보기" → 11~12월에는 미리 보기(결제 없음, "1월에 알려주세요" 알림 신청), 1월에 정식 안내·동의.

### 예외 상태
연동 거부(직접 입력 3개) / 민감정보 미동의(병원비 제외) / "모르겠어요" 답 / 문턱을 이미 넘은 경우.

### 시연 지표 패널 (데스크톱)
토스 연동 동의, 첫 결과까지 터치 수(목표 5~7), 연봉 추정 [맞아요], 슬라이더 계획 저장, 전환 알림 확인, 1월 구독 시작(시연), 도우미 제출 가이드 완료.
