# 십삼월 | 365일 관리하는 AI 절세 파트너

> **"미리보기에서 또 토해낸대요? 12월 31일 전까지, 조금이라도 덜 뱉어요."**
> 카드·월급·월세는 토스가 이미 알고 있어요. 남은 두 달, 어디로 결제할지만 정하세요.

토스에 연결된 카드·월급·월세 데이터로 올해 연말정산 결과를 자동으로 **예상**하고, 12월 31일까지 남은 지출을 신용카드·체크카드 중 어디로 결제하면 좋을지 보여주는 **토스 인앱 서비스 기획 프로젝트**예요.

- **대상:** 대한민국 근로소득자 (특히 지난해 추가 납부를 경험한 직장인)
- **성격:** 연말정산 예상 계산·정보 제공 도구. 세무 상담·신고 대행은 하지 않아요.
- **상태:** 기획·MVP 시연(페이크 도어 테스트) 단계. 시연 속 숫자는 모두 예시예요.

## 원칙

1. 확정 표현을 쓰지 않아요. 모든 금액은 "예상·추정"이고 환급·세금 감소를 보장하지 않아요.
2. 추가 소비를 유도하지 않아요. "원래 쓸 돈만 해당"이라고 항상 함께 안내해요.
3. 금융상품은 추천하지 않아요.
4. 구독은 압박하지 않아요. 11~12월은 무료 체험이고, 결제 동의는 구독 화면에서 따로 받아요.
5. 실제 결제·개인정보 저장은 없어요.

## 시연 방법

1. [`src/index.html`](src/index.html)을 브라우저로 열어요. (모바일 폭에서는 휴대폰 화면 하나로 보여요.)
2. **내 연말정산 바로 보기** → 이용 동의 → 토스 데이터 확인 → 질문 카드 → **올해 예상 결과**
3. **카드 사용 슬라이더**에서 남은 지출과 결제 수단 비율을 움직여 비교해요.
4. 홈의 시연 버튼으로 12월 14일(결제 수단 전환 알림) → 12월 31일(마무리 리포트) → 1월(구독·도우미)로 이동해요.
5. 데스크톱에서는 오른쪽 패널에서 핵심 이용 지표와 첫 결과까지의 터치 수를 확인할 수 있어요.

## 핵심 기능

- **토스 연동 자동 확인:** 카드 사용액·월급 입금·정기 이체(월세 후보)를 동의 범위 안에서 확인
- **터치 한 번 질문 카드:** 예 / 아니오 / 모르겠어요로 나머지 정보를 채움
- **카드 사용 슬라이더:** 남은 지출을 신용·체크카드로 나눴을 때의 예상 세금 비교
- **결제 수단 전환 알림:** 카드 공제 문턱·한도에 닿을 때만 알림
- **줄이는 방법 모아보기:** 효과 큰 순서와 마감(12월 31일 전 / 1월 확인)으로 정렬
- **1월 연말정산 도우미(구독):** 간소화 자료 비교, 누락 체크, 제출 가이드

## 참고

- 계산 모델은 시연용 근사값이에요. 공제율·한도는 출시 전에 최신 세법으로 검증이 필요해요.
- 이 프로젝트는 국세청·홈택스와 관련이 없어요.
- 디자인은 토스 디자인 시스템(TDS) 스타일을 참고했어요.
