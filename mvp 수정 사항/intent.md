## 1. 한 줄 의도
**사용자가 "내 상황"을 직접 넣고, 12월 31일 전에 할 수 있는 방법을 더 다양하게 보고, 1월 도우미(구독)까지 자연스럽게 알게 한다. 그리고 이 모든 것을 읽기 전에 눈으로 이해하게 한다.**

## 2. 배경
- MVP 초안은 흐름은 완성됐지만, 시연해 보니 아래 여섯 가지 피드백이 나왔다. (R5·R6은 이슈 #34 코멘트로 추가됨)

| # | 피드백 (이슈 #34) | 사용자 입장에서의 문제 |
|---|---|---|
| R1 | 큰 지출을 고르기만 할 수 있다 | 내 지출은 150만·50만·300만 같은 보기에 안 맞는다 |
| R2 | 월세 입력칸에 개월 수가 없다 | 올해 중간에 이사했거나 입주한 사람은 12개월로 계산돼 틀린다 |
| R3 | 방법이 카드 사용 위주다 | 기부 등 다른 절세 방안은 안 보여서 "내 경우엔 이것뿐인가" 하게 된다 |
| R4 | 구독 안내가 숨겨져 있다 | 1월에 구독으로 이어지는 흐름이 있는데 11~12월에는 찾을 수 없다 |
| R5 | 성과금 등 추가 입력칸이 없다 | 연봉 추정이 월급 기준이라 성과금이 빠져 예상이 실제와 달라진다 |
| R6 | 전체적으로 말이 너무 많다 | 읽기 전에 포기한다. 숫자·색·아이콘으로 한눈에 보여야 한다 |

## 3. 이번 수정으로 달라지는 것
- **입력의 자유도**를 높인다 (R1, R2): 보기 선택뿐 아니라 직접 입력.
- **방법의 폭**을 넓힌다 (R3): 카드 결제 수단 외에 기부 등 다른 방법도 효과 큰 순서로 보여준다.
- **다음 단계의 발견성**을 높인다 (R4): 구독 안내를 쉽게 찾게 하되 강요하지 않는다.
- **소득 입력의 정확도**를 높인다 (R5): 성과금 등 추가 소득을 따로 넣을 수 있게 해 예상을 현실에 가깝게 한다.
- **읽는 부담**을 줄인다 (R6): 설명 문장을 줄이고 숫자·색·아이콘 중심으로 바꾼다.

## 4. 바뀌지 않는 원칙 (PRD 11월 버전 기준)
1. **확정 표현 금지.** "무조건 환급", "0원" 같은 표현을 쓰지 않는다. 모든 금액은 "예상·추정"이다.
2. **추가 소비를 유도하지 않는다.** 기부·지출은 "원래 하려던 것만 해당"이라고 항상 함께 안내한다.
3. **세무 상담이 아니다.** 모든 결과 화면에 안내 문구를 유지한다.
4. **금융상품은 추천하지 않는다.** 연금저축·IRP 등은 "이미 넣고 있다면 한도 확인" 수준의 정보 안내만 한다.
5. **구독은 압박하지 않는다.** 11~12월은 무료 체험이고, 결제 동의는 구독 화면에서 별도로 받는다. 광고 팝업·강제 노출은 하지 않는다.
6. **실제 결제·개인정보 저장은 없다.** 모든 숫자는 시연용 예시다.
7. **말보다 눈으로.** 핵심은 큰 숫자·색·아이콘으로 먼저 보여주고, 설명은 짧게 하거나 접는다. 단, 1~3번 안내 문구는 줄이더라도 **없애지 않는다.**

## 5. 성공 기준 (수정 후 확인할 것)
| 항목 | 확인 방법 |
|---|---|
| 사용자가 자기 숫자로 계산해 볼 수 있다 | R1·R2 입력 후 결과가 입력값대로 바뀐다 |
| 카드 외 방법을 1개 이상 이해한다 | "줄이는 법" 탭에서 기부 등 다른 방법을 말로 설명할 수 있다 (사용자 5명 관찰) |
| 구독 안내를 도움 없이 찾는다 | 11~12월 흐름에서 안내 진입점을 찾는 데 걸리는 시간·터치 수 |
| 성과금을 넣으면 예상이 달라진다 | R5 입력 전후로 결과·문턱 진행률이 바뀐다 |
| 한눈에 이해한다 | 화면별 글자 수가 줄고, 사용자가 첫 화면에서 "결과와 할 일"을 말로 설명한다 (5명 관찰) |
| 기존 흐름이 깨지지 않는다 | 기존 핵심 경로(일반 / 월세+병원비 / 민감정보 미동의 / 연동 거부)가 그대로 동작 |

목표 수치(시간·터치 수)는 수정 전 기준선을 먼저 재고 정한다.

## 6. 하지 않는 것
- 새 화면 흐름 전체를 다시 설계하지 않는다.
- 실제 세법 규칙의 정밀 검증은 이번 범위가 아니다 (근사 모델 유지, 단 R3에서 쓰는 공제율은 출시 전 검증 필요 표시).
- 실제 결제, 로그인, 서버 저장은 만들지 않는다.
