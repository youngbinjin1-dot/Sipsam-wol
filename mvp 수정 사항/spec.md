## R1. 큰 지출 직접 입력

**현재** 카드 사용 슬라이더에서 "+ 큰 지출 추가"를 누르면 시트에 `노트북 150만원 / 50만원 / 300만원` 칩 3개만 있다.

**바꿀 동작**
- 시트에 **금액 직접 입력칸**(단위: 만원)을 추가한다. 기존 칩 3개는 빠른 선택으로 유지한다.
- 입력값은 숫자만 허용한다. 입력칸 위에 안내 문구: "12월에 원래 쓸 계획이던 금액만 넣으세요."
- 칩을 누르면 입력칸에 해당 금액이 채워지고, "적용" 버튼으로 확정한다.
- 확정한 큰 지출은 슬라이더 화면에 `큰 지출 ○○만원 포함` 태그로 보이고, "빼기"로 지울 수 있다(기존 동작).

**규칙**
| 입력 | 처리 |
|---|---|
| 빈 값, 0 | 적용 불가 ("금액을 입력해 주세요" 토스트) |
| 음수, 문자 | 입력되지 않음 (숫자만) |
| 상한 | 5,000만원 초과 시 "5,000만원까지 입력할 수 있어요" 안내 후 상한값 적용 |
| 소수점 | 만원 단위 정수로 반올림 |

**완료 조건**
- [ ] "큰 지출 추가"에서 직접 숫자(예: 80)를 입력하면 슬라이더 화면에 `큰 지출 80만원 포함`이 보이고 예상 결과가 바뀐다.
- [ ] 칩 3개로도 기존처럼 설정된다.
- [ ] 빈 값·0은 적용되지 않고 안내가 뜬다.
- [ ] "빼기"를 누르면 입력 전 상태로 돌아온다.

## R2. 월세 개월 수 입력

**현재** 월세 세액공제는 `월세 × 12개월` 고정으로 계산한다. 월세 금액만 입력(직접 입력) 또는 확인(질문 카드)한다.

**바꿀 동작**
- 월세 입력/확인 지점에 **"올해 낸 개월 수"** 선택(1~12개월)을 추가한다. 기본값 12.
- 적용 위치
  - 직접 입력(manual) 화면: "매달 내는 월세" 아래에 개월 수 선택.
  - 질문 카드 월세 질문: "네" 선택 직후 개월 수 선택 단계를 추가한다 (토스 연동 시 이체 횟수로 추정한 값을 기본값으로, 고칠 수 있게).
- 계산식 변경: `연 월세 합계 = 월세 × 개월 수` (연 1,000만원 한도는 유지) → 기존 세율(총급여 5,500만원 이하 17%, 8,000만원 이하 15%) 적용.
- "줄이는 법" 월세 카드의 효과 금액도 개월 수 기준으로 바뀐다.

**완료 조건**
- [ ] 월세 35만원 · 12개월과 35만원 · 6개월의 월세 공제 효과가 서로 다르게 표시된다 (6개월이 절반).
- [ ] 개월 수를 입력하지 않으면 12개월로 계산된다 (기존 결과와 동일).
- [ ] 월세 0원 또는 "월세 아니요"면 개월 수 질문이 나오지 않는다.
- [ ] 연 합계가 1,000만원을 넘는 경우 한도(1,000만원)까지만 반영된다.
- [ ] 기존 경로(월세 있음/없음, 모르겠어요)가 그대로 동작한다.

## R3. 사용 내역 외 다양한 절세 방안 추가

**현재** "줄이는 법" 목록은 카드 결제 수단(핵심) + 월세·부양가족·병원비(답에 따라) + 연금저축 안내로 구성되고, 사용자는 주로 카드 사용 내역을 만진다.

**바꿀 동작**
- 방법 목록에 **카드 외 방안**을 추가하고, 기존처럼 효과 큰 순서 + 마감(⏰ 12/31 전 / 1월 확인)으로 정렬한다.
- 새 방안은 **"해당될 때만"** 보여준다. 질문 카드에서 가볍게 확인하거나 방법 카드 안에서 직접 입력한다.

**후보 방안 (우선순위 순, 팀 합의 필요)**

| 순위 | 방안 | 마감 | 사용자 입력 | 효과 계산 | 비고 |
|---|---|---|---|---|---|
| 1 | **기부금 세액공제** | 12/31 전 기부분 | 올해 기부 금액(이미 한 것 + 예정) | 입력 금액 × 공제율 (근사) | **"원래 하려던 기부만"** 문구 필수. 기부를 권유하는 표현 금지 |
| 2 | 교육비 | 1월 증빙 확인 | 본인/자녀 교육비 대략 구간 | 근사 | 요건 설명이 세무 상담처럼 보이지 않게 |
| 3 | 의료비 (기존) | 1월 간소화 확인 | 구간 선택 (기존) | 기존 | 유지 |
| 4 | 청약저축 소득공제 | 12/31 전 납입분 | 납입 여부만 | **금액 계산 없음, 안내만** | 무주택 세대주 요건 안내 |
| 5 | 연금저축·IRP (기존) | 12/31 전 납입분 | 없음 | **금액 계산 없음, 안내만** | 금융상품 추천 금지 원칙 유지 |

**화면 변경**
- 줄이는 법 탭: 방법 카드 목록 위에 **구분 탭(칩)**: `전체 / 12월 31일 전 / 1월에 확인`.
- 올해 예상 결과(s04), 홈 "이번 주 할 일": 효과 상위 3개를 보여준다 (카드 외 방안이 효과가 크면 위로 올라온다).
- 기부금 카드: 금액 직접 입력(만원) 후 `약 ○○원 줄어요`가 바뀐다. 입력 전에는 "금액 계산 없음".
- 모든 새 카드에 "원래 하려던 것만 해당" + 세무 상담 아님 안내.

**규칙**
- 계산에 쓰는 공제율·한도는 **근사값**이며 카드에 "확인 필요" 태그를 단다. 출시 전 최신 세법으로 검증한다 (open question).
- 입력하지 않았거나 "모르겠어요"는 계산에서 제외하고 "확인 필요"로 표시한다 (기존 규칙 동일).
- "모두 해당되면 최대 약 ○○원" 합계는 카드 전환을 제외한 계산 가능한 방안만 더한다.

**완료 조건**
- [ ] 줄이는 법 탭에 카드 외 방안이 최소 2개(기부금 + 1개) 더 보인다.
- [ ] 기부금 금액을 입력하면 효과 금액이 바뀌고, 입력 전에는 "금액 계산 없음"이다.
- [ ] `12월 31일 전 / 1월에 확인` 필터가 동작한다.
- [ ] 새 방안 카드마다 "원래 하려던 것만 해당" 안내가 있다.
- [ ] 효과가 가장 큰 방안이 목록 맨 위에 온다.
- [ ] 연금저축·청약은 금액 계산 없이 안내만 한다.

**열린 질문 (R3)**
1. 후보 5개 중 이번에 넣을 범위는? (최소안: 기부금 + 청약 안내)
2. 기부금 공제율을 어떻게 근사할지, 정치자금·법정기부금 등 구분을 둘지?
3. 교육비는 질문 카드에 넣을지, 방법 카드 내 입력으로만 둘지?

## R4. 구독 안내 발견성 개선

**현재** 구독 안내는 **1월 단계 홈**(구독 알아보기)과 12월 마무리 리포트의 "1월 연말정산 같이 챙기기"로만 이어진다. 11~12월 홈·줄이는 법·내 정보에는 구독 진입점이 없거나 문구만 있다.

**바꿀 동작**
진입점 3곳을 추가한다 (강제 노출·팝업은 없음).

| 위치 | 형태 | 문구(안) |
|---|---|---|
| 홈 (11·12월) | 스크롤 하단 카드 | "1월에 연말정산 도우미가 열려요 · 지금은 무료 체험 중이에요" → `구독 알아보기` |
| 줄이는 법 탭 | 목록 하단 카드 | "1월에 확인할 항목은 도우미가 같이 챙겨줘요" → `구독 알아보기` |
| 내 정보 | 구독 카드 안 버튼 | 기존 설명 아래 `구독 알아보기` 버튼 추가 |

- 세 진입점 모두 구독 안내(s09)로 이동한다. 거기서 "나중에 할게요"로 돌아올 수 있다.
- 시연 지표 패널에 **"구독 안내 열어봄"** 항목을 추가한다 (진입점 위치도 기록: 홈/줄이는 법/내 정보).
- 1월 단계 홈은 기존 구독 카드를 유지하되, 카드 순서를 위로 올려 첫 화면에서 보이게 한다.

**규칙**
- 11~12월은 "무료 체험 중" 문구를 같이 보여 결제 압박으로 보이지 않게 한다.
- 결제 동의는 구독 선택(s10)의 별도 체크로만 받는다 (변경 없음).
- 같은 세션에서 카드는 1곳당 1개만, 닫기·접기 등으로 숨길 수 있게 하지는 않는다 (조용한 카드 형태 유지).

**완료 조건**
- [ ] 11월 홈, 12월 홈, 줄이는 법, 내 정보 각각에서 구독 진입 카드/버튼이 보이고 s09로 이동한다.
- [ ] s09에서 "나중에 할게요"를 누르면 원래 탭으로 돌아온다.
- [ ] 지표 패널에 "구독 안내 열어봄"이 기록된다.
- [ ] 어떤 경로에서도 팝업·전체 화면 광고가 뜨지 않는다.
- [ ] 1월 홈에서 구독 카드가 첫 화면(스크롤 없이)에 보인다.

## R5. 성과금 등 추가 입력칸

**현재** 연봉은 "월 실수령액 약 320만원 → 연봉 약 4,200만원"으로 **추정**하고, 고치려면 연봉 입력 시트(고칠래요)에서 연봉 전체를 다시 넣어야 한다. 성과금·상여를 따로 넣는 곳이 없다.

> 성과금은 공제가 아니라 **소득**이다. 총급여가 바뀌면 카드 공제 문턱(총급여의 25%), 기본 세액, 월세 공제율 구간(5,500만원/8,000만원)이 모두 바뀐다.

**바꿀 동작**
- **자동으로 찾은 정보(s02)**: 연봉 카드 아래에 **"성과금·상여가 따로 있나요?"** 입력칸(단위: 만원, 선택)을 추가한다.
- **직접 입력(manual)**: "연봉" 아래에 **"성과금·상여(만원, 없으면 0)"** 칸을 추가한다.
- 입력값은 **세전 금액**으로 총급여에 더해 계산한다 (총급여 = 연봉 + 성과금).
- 입력칸 위 안내: "세전 금액으로 넣어주세요. 연봉에 이미 포함돼 있으면 넣지 않아도 돼요." (이중 입력 방지)
- 입력하면 연봉 옆 `추정` 배지 옆에 `성과금 포함` 표시가 붙는다.
- 이 칸은 확장 가능한 "추가 입력" 자리로 둔다 (이후 다른 소득을 같은 방식으로 추가할 수 있게).

**규칙**
| 입력 | 처리 |
|---|---|
| 빈 값 | 0으로 처리 (기존 결과와 동일) |
| 음수·문자 | 입력되지 않음 |
| 상한 | 1억원 초과 시 "1억원까지 입력할 수 있어요" 안내 후 상한 적용 |
| 총급여 변화 | 카드 문턱, 문턱 진행률, 기본 세액, 월세 세율 구간을 모두 다시 계산 |

**완료 조건**
- [ ] 성과금 500만원을 입력하면 총급여가 그만큼 늘어나고 카드 공제 문턱(총급여의 25%)이 125만원 올라 진행률이 낮아진다.
- [ ] 성과금을 비워 두면 기존 결과와 같다.
- [ ] 총급여가 월세 공제율 구간(5,500만원)을 넘으면 월세 효과 금액이 바뀐다.
- [ ] 직접 입력 경로(manual)에도 같은 칸이 있고 같은 결과가 나온다.
- [ ] "연봉에 이미 포함돼 있으면 넣지 않아도 돼요" 안내가 보인다.

**열린 질문 (R5)**
1. 성과금 외에 입력칸에 함께 둘 항목은? (상여, 인센티브, 명절 보너스 등 하나의 칸으로 합칠지)
2. 토스 연동 시 급여 입금액에서 성과금 입금을 자동으로 구분할 수 있는지 (불가하면 직접 입력만)

## R6. 전체 화면: 말 줄이고 시각적으로

**현재** 거의 모든 화면에 설명 문장, 작은 안내, 면책 문구가 길게 붙어 있어 읽기 전에 포기하기 쉽다.

**바꿀 동작**
원칙은 "**큰 숫자·색·아이콘 먼저, 설명은 짧게 또는 접기**"다.

| 기준 | 내용 |
|---|---|
| 글자 수 | 카드 설명은 **2문장 이하**(한글 약 60자), 화면 제목은 한 줄 |
| 보조 안내 | 화면당 **최대 2개**. 더 있으면 "자세히 보기"로 접는다 |
| 핵심 숫자 | 예상 금액·효과 금액은 크게, 색으로 구분 (추가 납부=빨강, 줄어드는 금액=파랑) |
| 상태 표시 | 문턱 진행률은 막대, 마감은 아이콘+색 칩(⏰ 12/31 전 / 1월 확인) |
| 비교 | "지금처럼 vs 이 계획"은 문장 대신 **막대 2개 또는 숫자 대비**로 보여준다 |
