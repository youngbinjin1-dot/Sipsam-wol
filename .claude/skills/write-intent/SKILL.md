# write-intent — 팀 공통 intent 작성 스킬

이 저장소의 모든 intent는 `intent/` 아래 **한 기능 = 한 폴더**로 모은다. 규칙의 원본은 `intent/README.md`이고, 이 스킬은 그 규칙을 그대로 따른다.

## 순서

1. `intent/README.md`를 읽고 현재 intent 목록을 확인한다. 같은 기능 폴더가 이미 있으면 새로 만들지 않고 그 폴더의 파일을 고친다.
2. 폴더를 만든다: `intent/YYYY-MM-DD-영문-슬러그/`
   - 날짜는 오늘(Asia/Seoul) 기준.
   - 슬러그는 영문 소문자·숫자·하이픈만.
3. `intent/_template.md`를 복사해 `intent.md`를 만들고 빈칸을 채운다.
   - `상태:`는 `draft`로 시작한다.
   - 작성자에 사람 이름 또는 에이전트 이름을 적는다.
4. 요청이 있을 때만 `spec.md`(요구사항·디자인 결정), `plan.md`(구현 계획)를 같은 폴더에 추가한다.
5. `intent/README.md`의 "현재 intent 목록" 표에 한 줄을 추가한다.
6. 구현물은 `src/`, 장애·회고는 `lessons/`에 두고 intent에서 상대 경로로 링크한다.

## 작성 원칙 (이 서비스 공통)

- 모든 금액은 "예상·추정". 환급·세금 감소를 보장하는 표현을 쓰지 않는다.
- 세무 상담·신고 대행으로 오해될 표현을 쓰지 않는다.
- 추가 소비를 유도하지 않고, 금융상품을 추천하지 않는다.
- 쉬운 말로 쓰고, 전문 용어는 처음 나올 때 괄호로 풀어 쓴다.

## 끝내기 전 확인

- [ ] 폴더 이름이 `YYYY-MM-DD-슬러그` 형식인가
- [ ] `intent.md`에 한 문장 의도·하지 않는 것·성공 기준이 있는가
- [ ] `intent/README.md` 목록에 추가했는가
- [ ] 상대 링크가 깨지지 않았는가
