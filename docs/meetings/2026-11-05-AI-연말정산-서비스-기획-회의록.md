## 1. 회의 핵심 요약

이번 회의에서는 연말정산 시기에만 사용하는 일회성 서비스의 한계를 극복하고, **사용자의 소비와 절세를 1년 내내 관리하는 AI 금융 파트너**로 서비스를 발전시키는 방향을 논의했다.

| 항목 | 내용 |
| --- | --- |
| 핵심 콘셉트 | 연말정산 결과 조회 중심에서 연중 절세 계획 및 소비 관리 중심으로 전환 |
| 주요 차별화 방향 | 미래 지출 시뮬레이션, 개인별 절세 현황, 쉬운 세금 설명, 맞춤형 알림 |
| 비즈니스 모델 | 기본 기능 무료 제공, 심화 분석과 절세 계획을 유료화하는 프리미엄 모델 중심 |
| 주요 검토 과제 | 세무 관련 법률, 금융 데이터 연동 가능성, 기존 서비스와의 실질적인 차별성, 초기 개발 범위 |

## 2. 서비스 콘셉트

### 제안된 서비스 정의

> **연말에 돌려받는 돈부터 오늘 놓치는 혜택까지, 365일 내 돈을 관리하는 AI 절세 파트너**

기존 연말정산 서비스는 주로 연말 또는 연초에 이용하지만, 기획 서비스는 연중 지속적으로 소비 데이터를 확인하고 절세 가능성을 예측하는 방향이다.

| 구분 | 기존 서비스의 주요 이용 방식 | 기획 서비스의 목표 |
|--------|--------|--------|
| 이용 시점 | 연말·연초 집중 | 365일 상시 |
| 주요 목적 | 환급액 확인·신고 | 절세 계획·소비 관리 |
| 사용자 행동 | 필요할 때 조회 | 월별 확인 및 조정 |
| 정보 제공 | 결과 및 일반적인 팁 | 개인 상황 기반 시뮬레이션 |
| 경험 | 사용자가 직접 검색 | AI가 이해와 판단을 보조 |

단, 기존 서비스에도 일부 유사 기능이 있어 실제 차별성은 추가적인 경쟁사 조사가 필요하다.

## 3. 핵심 기능 논의

회의에서 제안된 기능을 우선순위에 따라 재정리했다. 아래 우선순위는 회의 내용을 바탕으로 한 권장 분류이며 최종 확정안은 아니다.

| 우선순위 | 기능 | 주요 내용 |
|--------|--------|--------|
| P0 | 연말정산 예상 시뮬레이션 | 예상 환급·추가 납부액 확인 |
| P0 | 미래 지출 시뮬레이션 | 지출액·카드 유형을 변경하며 예상 결과 비교 |
| P0 | 월별 절세 체크인 | 소비 및 공제 현황을 월별로 확인 |
| P0 | 쉬운 세금 용어 설명 | 어려운 세금 용어를 쉬운 언어로 풀이 |
| P1 | AI 세금 안내 챗봇 | 준비 서류, 공제 조건, 적용 제외 이유 안내 |
| P1 | 맞춤형 절세 알림 | 사용 현황에 따른 체크카드 전환 시점 등 안내 |
| P1 | 정부 지원 정책 추천 | 연령·상황별 정책 및 혜택 정보 제공 |
| P2 | 금융 데이터 자동 연동 | 카드 및 계좌 정보 자동 반영 |
| P2 | 정책 업데이트 콘텐츠 | 연말정산 제도 변경 및 새로운 혜택 안내 |

### 핵심 사용자 플로우

| 단계 | 사용자 행동과 제공 정보 |
| --- | --- |
| 1. 초기 정보 입력 | 전년도 연봉 · 예상 연봉 상승률 · 공제 관련 정보 |
| 2. 현재 절세 상태 분석 | 예상 세액 · 지출 현황 · 적용 가능한 공제 |
| 3. 미래 지출 시뮬레이션 | 신용카드/체크카드 비중 및 예상 지출 조정 |
| 4. 월별 체크인 및 알림 | 실제 소비 반영 · 예상 결과 업데이트 |
| 5. 연말정산 준비 | 준비 서류 · 적용 조건 · 연간 결과 확인 |

다음 해에도 지속적으로 관리

### UX 측면에서 강조된 사항

- 사용자가 세금 지식을 갖추지 않아도 이해할 수 있어야 한다.
- 특정 공제가 적용되지 않는다면 단순히 '불가'라고 표시하지 않고 이유를 설명한다.
- 절세를 위해 무조건 소비를 늘리도록 유도하지 않는다.
- 사용자가 직접 목표를 설정하고 다양한 소비 시나리오를 비교할 수 있도록 한다.
- 초기 정보는 동의를 받아 저장하고 반복 입력을 최소화하는 방향을 검토한다.

## 4. 수익 모델 논의

회의에서는 세 가지 수익화 방향을 검토했다.

| 모델 | 내용 | 회의 결과 |
|--------|--------|--------|
| B2C 프리미엄 | 심화 절세 분석, 지출 시뮬레이션, 월별 리포트 | 핵심 모델로 논의 |
| B2B 기업 솔루션 | 직원 대상 연말정산 교육·준비 지원 | 기업의 구매 이유 추가 검토 |
| 광고·제휴 | 금융사 광고 및 관련 서비스 제휴 | 보조 수익원으로 검토 |

### 프리미엄 요금제 구상

| 요금제 | 가격 | 제공 기능 |
| --- | --- | --- |
| 무료 | 무료 | 기본 환급액 예측, 정부 정책 검색, 기본 세금 정보 안내 |
| 프리미엄 | 연 19,000~29,000원 (회의 제안가) | 미래 지출 시나리오 비교, 월별 절세 리포트, 맞춤형 준비 체크리스트, 심화 절세 계획 |

**주요 논의**

사회초년생이나 연말정산에 익숙하지 않은 사용자는 정보를 직접 찾는 시간과 부담을 줄일 수 있다면 유료 서비스를 이용할 가능성이 있다는 의견이 나왔다. 반면 절약을 목적으로 사용하는 서비스에 비용을 지불할지에 대한 의문도 제기됐다.

따라서 실제 지불 의향과 적정 가격에 대한 사용자 검증이 필요하다.

## 5. 경쟁 서비스 분석

회의 중 언급된 주요 경쟁 서비스는 홈택스(국세청 세금 신고 서비스)와 삼쩜삼(한국 세금 환급 서비스)이다.

| 비교 항목 | 홈택스 | 삼쩜삼 | 기획 서비스 |
|--------|--------|--------|--------|
| 핵심 가치 | 공식 세금 신고·조회 | 간편한 환급 관련 서비스 | 연중 절세 관리 |
| 사용자 경험 | 정보가 많고 복잡하다는 의견 | 상대적으로 간편하다는 의견 | 쉬운 설명과 지속적 관리 |
| 절세 정보 | 공제 및 세법 정보 제공 | 절세 팁 제공 | 개인별 시나리오 중심 |
| 차별화 과제 | 복잡한 정보 탐색 | 기존 간편 서비스와의 경쟁 | 관리 기능의 실질적 효용 검증 |

위 표는 회의 참석자들의 사용 경험과 의견을 정리한 것으로, 각 서비스의 전체 기능을 검증한 비교표는 아니다.

특히 삼쩜삼에 이미 예상보다 다양한 기능이 있다는 사실을 회의 중 확인했으며, 이에 따라 단순 기능 추가만으로는 차별화가 부족할 수 있다는 의견이 나왔다.

**도출된 방향**

사용자의 입력 부담을 줄이고 매달 관리할 이유를 제공하는 것이 중요하다.

## 6. 법률 및 기술적 제약

| 검토 항목 | 회의에서 나온 문제 | 대응 방향 |
|--------|--------|--------|
| 세무 관련 법률 | 세무사 업무와의 경계 | 일반 정보·계산·교육 중심 설계, 개별 세무 상담 해당 여부 검토 |
| 금융 마이데이터 | 카드·계좌 데이터 연동 | 초기에는 직접 입력 방식 채택 |
| 개인정보 보호 | 소득·소비 데이터 저장 | 최소 수집, 명시적 동의, 안전한 저장 |
| AI 정보 정확성 | 잘못된 절세 정보 제공 가능 | 공식 자료 기반 검증 및 기준일 표시 |
| 개발 리소스 | 약 1주일의 프로토타입 제작 기간 | 핵심 시뮬레이션 중심으로 범위 축소 |

회의에서는 금융 데이터 자동 연동을 장기 기능으로 검토하되, **초기 프로토타입은 사용자가 직접 정보를 입력하는 구조**가 현실적이라는 의견이 나왔다.

또한 AI가 법적 문제가 없다고 답변했다는 사실만으로 적법성이 보장되지는 않으므로, 실제 서비스화 단계에서 별도 법률 검토가 필요하다.

## 7. 시장 규모 및 해외 진출

### TAM · SAM · SOM

회의에서는 AI를 활용한 시장 규모 추정치를 공유했지만 산출 근거에 대한 의문이 제기됐다.

| 지표 | 회의 중 언급 내용 | 후속 검토 |
|--------|--------|--------|
| TAM | 약 2,940만 명 추정치 언급 | 전체 직장인 등을 포함한 범위 재정의 |
| SAM | 구체적인 확정 수치 없음 | 실제 서비스 대상과 접근 가능 시장 정의 |
| SOM | 초기 11만 명 및 보수적 추정치 언급 | 기간·전환율·획득 비용 기반 재산정 |

이 숫자들은 확정된 시장 데이터가 아닌 회의 중 공유된 추정치다. 발표 자료에는 출처와 계산 과정을 확인한 뒤 사용해야 한다.

### 해외 진출 전략

| 국가 | 검토 방향 | 논의 내용 |
| --- | --- | --- |
| 일본 | 우선 검토 국가 | 서류 준비 및 세금 관련 절차를 안내하는 서비스에 기회가 있을 것이라는 의견. 현지 제도와 경쟁 서비스 조사 필요. |
| 싱가포르 | 차별화 모델 검토 | 세금 신고 자동화 수준이 높다는 점을 고려해 생활 혜택과 연중 금융 계획 관리 중심으로 접근하는 방안. |

해외 진출 시에는 공통적인 금융 관리 UX를 유지하면서 국가별 세금 제도, 공제 기준, 정책 데이터를 별도로 적용하는 구조가 제안됐다.

## 10. 회의 종합 인사이트

이번 회의에서 가장 중요한 변화는 **연말정산을 잘하는 앱에서, 연말정산을 미리 준비하도록 돕는 앱으로 관점을 전환했다는 점**이다.

UX/UI 프로젝트 관점에서 다음 세 가지가 중요하다.

1. **문제 정의** — 사용자가 어려워하는 것은 세금 계산 자체뿐 아니라 무엇을 언제 준비하고, 왜 공제가 적용되지 않는지 이해하기 어렵다는 점이다.
2. **핵심 경험** — 현재 상태를 확인하고 미래 소비를 조정했을 때 결과가 어떻게 달라지는지 즉각적으로 보여주는 시뮬레이션이 서비스의 중심 경험이 될 수 있다.
3. **프로젝트 범위** — 일주일 내 프로토타입이라면 금융 연동, 정책 추천, 챗봇을 모두 구현하기보다 정보 입력 → 예상 결과 → 시나리오 비교 → 월별 관리의 흐름을 완성하는 것이 적절하다.

**다음 회의에서 우선 결정할 질문**
