# PEST 분석: AI 연말정산 사전 관리 서비스를 둘러싼 트렌드

> 정치·경제·사회·기술 변화가 우리 서비스에 미치는 영향을 구조화함
> 작성일: 2026-11-05 · 근거: 저장소 문서(PRD v3, 11/5 회의록, 페르소나 분석, 카드뉴스, 국내 사업계획) + 외부 자료

## 분석

| 구분 | 분석 질문 | 세부 이슈 |
|---|---|---|
| **Political** | 정책·규제가 영향을 주는가? | 세무사법(개별 상담·신고대행 경계), AI 기본법 시행(2026.1), 마이데이터 전 분야 확대, 매년 바뀌는 공제율·한도, 금융상품 중개 규제 |
| **Economic** | 소비·투자 여건은 어떤가? | 고물가 속 예상 못한 추가 납부 부담, '절약 서비스'에 대한 지불 의사, 무료 대체재(홈택스·삼쩜삼), 기업 복지 예산(B2B) |
| **Social** | 생활 방식이 바뀌는가? | 2539 직장인의 세금 이해 부족, '절약 = 절세' 오해, 1월에야 확인하는 습관, 1인·월세 가구, 숏폼·카드뉴스형 정보 소비 |
| **Technological** | 기술 변화가 기회인가? | 생성형 AI 설명·명세서 사진 인식, 규칙 기반 세액 엔진, 데이터 연동(간소화·마이데이터), 앱인토스 미니앱, AI 오답 위험 |

## 요약

세법·AI·데이터 관련 규제가 동시에 바뀌고 있지만, **추가 납부를 겪은 직장인의 "미리 알고 싶다"는 수요**와 **개인 데이터 연동 확대**가 맞물리는 시기.

| 기회 | 위협 |
|---|---|
| 추가 납부 경험 → 4월부터 관리하려는 동기 | 무료 서비스(홈택스 미리보기·삼쩜삼)와 기능이 겹침 |
| 개인정보 전송요구권 확대로 입력 부담을 줄일 여지 | 절약 목적 서비스에 돈을 낼지 불확실 |
| 추천·보조형 AI는 규제 부담이 비교적 낮음 | 세법 개정 시 계산·안내를 매년 갱신해야 함 |
| 사회초년생의 낮은 세금 이해도 → 쉬운 설명 수요 | AI 오답·세무 자문 경계 문제가 신뢰 하락으로 이어짐 |

> **주의:** PEST는 아이디어 평가가 아니라, 아이디어가 놓인 배경을 읽는 도구임
