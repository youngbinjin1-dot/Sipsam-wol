# 02 경쟁 압력 — 5-Force 분석

> 5-Force: 업계의 경쟁이 얼마나 치열한지 5가지 힘으로 따져보는 분석 도구
> 목표: 구조적 난이도와 방어 지점을 찾는다

## 5가지 힘

| 5가지 힘 | 우리 상황 | 강도 |
|---|---|---|
| **① 기존 경쟁자** (이미 있는 비슷한 서비스) | 삼쩜삼, 은행·카드사 앱 연말정산 미리보기, 뱅크샐러드 등 이미 많음 | 높음 |
| **② 신규 진입자** (새로 들어올 회사) | 마이데이터(흩어진 금융 정보를 모아 쓰는 제도) 덕분에 다른 핀테크(금융+기술 회사)도 쉽게 뛰어들 수 있음 | 중~높음 |
| **③ 대체재** (다른 방법으로 같은 문제를 해결하는 것) | 홈택스 무료 미리보기, 회사 연말정산, 세무사 | 높음 |
| **④ 구매자 교섭력** (사용자가 가진 힘) | 무료 대안이 많고 앱 바꾸기 쉬움 → 사용자가 쉽게 떠날 수 있음 | 높음 |
| **⑤ 공급자 교섭력** (우리가 의존하는 쪽의 힘) | 홈택스 데이터, 토스 플랫폼 정책에 영향을 받음 (토스 인앱이라서) | 중간 |

**→ 구조적 난이도: 높음** (경쟁이 치열하고 사용자를 붙잡기 어려운 시장)

## 방어 지점 (우리가 버틸 수 있는 강점)

- **토스 데이터 자동 연결** → 입력이 거의 없어서, 한 번 쓰면 다른 앱으로 옮기기 귀찮아짐
- **환급금 수수료 없음** → 삼쩜삼(수수료 있음)과 확실히 다른 점
- **365일 관리** → 연말에만 쓰는 게 아니라 매달 쓰는 습관을 만들어 이탈을 막음

## Statement 빈칸

> 경쟁 압력은 **"환급 대행 앱·은행 앱·무료 홈택스 등 대안이 많고 사용자가 쉽게 갈아탈 수 있어 높은 수준"**이며

짧은 버전: **"유사 서비스와 무료 대안이 많아 높은 수준"**
