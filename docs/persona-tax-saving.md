# 페르소나 기반 절세 효과 분석

> ⚠️ 모든 금액은 **가정치(근사 계산)** 입니다. 공제율·한도는 소득세법 기준으로 잡았으며, 올해 귀속 연도 기준 개정 여부를 국세청 자료로 검증해야 합니다.

## 1. 서비스 3대 기능
| 기능 | 역할 |
|------|------|
| 연말정산 예상 시뮬레이션 | 지금 기준 예상 환급/추가 납부를 미리 이해 |
| 월별 절세 체크인 | 지출·공제 상황을 주기적으로 점검하고 놓친 공제를 알림 |
| 미래 지출 시나리오 | 여행·의료비 등 계획 변경 전/후 예상 결과 비교 |

## 2. 두 페르소나 한눈에 보기 (소득 동일)

| 구분 | 👩 지우 (알뜰형) | 👩 소연 (소비형) |
|------|----------------|----------------|
| 나이 / 직업 | **26세 (20대 중반)**, 사회초년생 | **33세 (30대)**, 경력 직장인 |
| **총급여 (세전)** | **연 5,000만원 (월 약 417만원)** | **연 5,000만원 (월 약 417만원)** |
| **실수령 (세후)** | **월 약 355만원** | **월 약 355만원** |
| 성향 | 아끼고 모으는 게 목표 | 쓰고 즐기는 게 목표 |
| 거주 | 본가 거주 | 월세 거주 |
| **월세** | **0원** | **월 50만원 (연 600만원)** |
| **월 소비** | **약 100만원** | **약 233만원** |
| 연 소비 | 약 1,200만원 | 약 2,800만원 |
| 결제 수단 | 체크카드 위주 | 신용 2,000만 / 체크 800만 |
| 월 저축 | **250만원** (일반 적금·예금) | 20만원 |
| 연금저축·IRP | 없음 | 없음 |
| 여행 | 거의 안 감 | 연 300만원 (해외 1~2회) |

> 세후 월 약 355만원 = 세전 417만원 − 4대보험 약 39만원 − 소득세·지방소득세(매월 원천징수) 약 23만원 (근사 가정치)

### 월 소비 패턴
| 항목 | 지우 | 소연 |
|------|-----:|-----:|
| 식비·외식·카페 | 35만 | 70만 |
| 쇼핑·미용 | 25만 | 60만 |
| 문화·취미 | 10만 | 30만 |
| 여행 (월 환산) | 0 | 25만 |
| 교통 | 8만 | 15만 |
| 통신·기타 | 22만 | 33만 |
| **합계** | **100만** | **233만** |

### 연말정산 결과 (서비스 전)
| 항목 | 지우 | 소연 |
|------|------|------|
| 카드 소득공제 | **0원** (문턱 1,250만원 미달) | 한도 300만원 → 세금 약 45만원 절감 |
| 월세 세액공제 | **해당 없음** | 600만원 × 17% = 약 100만원 |
| 연금저축·IRP | 0원 (공제 안 되는 적금에 저축) | 0원 |
| **최종** | **약 -100만원 (납부)** | **약 +50만원 (환급)** |

> 핵심: **"절약"과 "절세"는 다르다.** 공제는 공제 항목에 쓴 돈에만 붙는다. 지우는 가장 열심히 모았는데 세금 혜택은 하나도 받지 못한다.

## 3. 서비스 적용 후 — 지우 (26세)
| 단계 | 서비스 기능 | 내용 | 효과 |
|------|------------|------|------|
| 1 | 시뮬레이션 | 11월에 "약 -100만원 납부 예상" 인지 | 문제를 미리 파악 |
| 2 | 월별 체크인 | "연금저축 납입 0원, 공제 한도 600만원 남음" 알림 | 월 250만원 저축 중 50만원을 연금저축으로 |
| 3 | 시나리오 비교 | "적금 600만원 → 연금저축으로 옮기면?" | 저축액 그대로 **+99만원** (600만 × 16.5%) |
| 4 | 시나리오 비교 | (세대주라면) 청약저축 300만원 추가 | 약 +18만원 |

- **결과: 약 -100만원 → 약 +17만원 (최대 117만원 개선)**
- 주의 안내: 연금저축 중도 해지 시 기타소득세 16.5% → **유동성 경고**를 함께 제공
- 정직한 조언: "카드공제를 받으려고 소비를 늘리지 마세요" (100원 쓰고 15~30원 공제는 절세가 아님)

## 4. 서비스 적용 후 — 소연 (33세)
| 기능 | 내용 | 효과 |
|------|------|------|
| 월별 체크인 | 7월경 "카드 공제 한도(300만원) 소진" 알림 | 이후 결제는 공제가 안 된다는 점 인지 |
| 미래 지출 시나리오 | 12월 해외여행 300만원 결제 시뮬레이션 | 공제 영향 0원 → 계획 변경 판단 근거 |
| 절세 추천 | 월 17만원씩 연금저축 200만원 | **+33만원** (200만 × 16.5%) |
| 대중교통·전통시장 | 별도 한도 항목 안내 | 소액 추가 공제 |

- **결과: 약 +50만원 → 약 +83만원 (+33만원)**
- 소연의 환급은 "이득"이 아니라 지출의 일부 환원 (카드로 더 쓴 1,600만원의 일부)임을 보여주는 비교 화면 제공

## 6. 비즈니스 모델 시사점
- **고객 가치**: "얼마 돌려받나"가 아니라 "내 행동 중 어디가 세금과 연결되는지"를 이해시켜 억울함을 줄임
- **수익 후보**: 연금저축/IRP·청약 상품 연계(제휴 수수료), 프리미엄 구독(월별 체크인·가족 시나리오), 세무 상담 연결, 5월 종합소득세 서비스 교차 판매
- **UX 과제**: 월세·거주 형태 등 추가 입력을 최소화하는 설계

## 7. 검증 필요 항목
- [ ] 올해 귀속 기준 공제율·한도 재확인 (연금저축 세액공제율, 카드 공제 한도, 월세 공제 요건)
- [ ] "-100만원 / +50만원"은 원천징수(기납부세액) 수준에 따라 달라지는 가정치임을 발표에서 명시
- [ ] 34세 이하 청년 중소기업 취업자 소득세 감면(해당 시 90%) 등 연령 특화 혜택 검토 (지우·소연 모두 해당 가능)
