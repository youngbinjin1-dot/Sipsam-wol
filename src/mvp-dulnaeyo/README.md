## 실행
빌드 없이 브라우저로 엽니다.

| 주소 | 설명 |
|---|---|
| `index.html` | 카피 A. `?v=b`, `?v=c` 로 대안 카피, `?admin=1` 로 이 브라우저의 집계 |
| `app.html` | 앱 모의실행. 데스크톱에서는 오른쪽에 시연 진행·핵심 지표 패널 |

## app.html 흐름 (회원가입·로그인 없음)
이용 동의(맨 앞 한 번) → 토스 데이터 연동(거부 시 3가지 직접 입력) → 자동으로 찾은 정보 확인 → 질문 카드 → 올해 예상 결과 + **지금 바꿀 수 있는 방법** → 카드 사용 슬라이더 → 저장·알림 → 홈 / 줄이는 법 탭 → 12월 전환 알림 → 12월 마무리 리포트 → 1월 구독 안내·동의(시연) → 연말정산 도우미(자료 비교·제출 가이드) → 마무리.

## 주의
- 모든 숫자는 예시이고 근사 계산입니다. 세무 상담·신고 대행이 아니며 국세청·홈택스와 무관합니다.
- 구독 가격(14,900원/24,900원)은 시연용 예시이고 결제 정보는 받지 않습니다.
- 입력값은 저장·전송하지 않습니다(`index.html`의 클릭 기록만 브라우저 localStorage에 남음).
